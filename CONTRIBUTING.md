# Contributing to MedSync AI

Thanks for improving MedSync AI. Please keep changes focused, accessible, and safe for a health-adjacent product.

## Before you begin

1. Open an issue or discussion for substantial changes.
2. Create a branch from `main`.
3. Install dependencies with `npm install` and run `npm run dev`.

## Pull requests

- Explain the problem, solution, and user-facing impact.
- Add or update tests where practical.
- Run `npm run build` before requesting review.
- Never include secrets, recordings, or personal health information.
- Preserve the grayscale clinical design system and WCAG-conscious contrast.

## Health-safety changes

Changes to triage, medical content, emergency guidance, or drug-interaction logic require extra review. Avoid claims of diagnosis or treatment, retain the medical disclaimer, and use conservative escalation guidance.
